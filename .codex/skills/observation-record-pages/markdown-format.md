# 観測記録 Markdown 仕様（初版）

この仕様は `templates/observation-entry.md` と常に同期させる。

## 1. ファイル配置

- パスは `upload/<year>/<date>/index.md` 固定。
- 画像ファイルは `index.md` と同階層に置く。
- `<year>` は4桁（例: `2024`）。
- `<date>` は6桁 `YYMMDD`（例: `240410`）。

## 2. frontmatter

frontmatter は任意。年と日付の決定には使わない。

利用可能キー（すべて任意）:

- `title`: ページタイトル補助
- `diaryTitle`: 日記セクション見出し
- `location`: 観測地
- `weather`: 天候
- `tags`: 配列

## 3. 本文構造

必須/任意ルール:

- `## 日記` は任意（存在しなくてもよい）
- `## 観測記録` は必須
- `## 観測記録` 配下に対象ブロックを1件以上置く
- 見出し行（`##` / `###` / `####`）は行頭から書く（先頭スペースを入れない）

対象ブロック構造（繰り返し）:

1. `### <対象識別名>`
2. `#### タイトル`
3. `#### 天体写真`
4. `#### 撮影データ`
5. `#### 所感`

## 4. 各セクション記述ルール

`#### タイトル`:

- 1行の短い見出しテキストを置く。

`#### 天体写真`:

- Markdown 画像記法 `![代替テキスト](ファイル名)` を1枚以上置く。
- パスは同階層基準で相対指定する（例: `m42-final.jpg`）。

`#### 撮影データ`:

- 箇条書きで書く。
- 推奨キー:
  - `撮影日時`
  - `撮影場所`
  - `機材`
  - `露光`
  - `枚数`

`#### 所感`:

- 自由文で記述する。
- 1段落以上を推奨。
- 複数段落にする場合は空行で段落を分ける。

### 本文の独自装飾タグ（任意）

- 部分装飾は次のタグを使用できる:
  - `{red}...{/red}`
  - `{blue}...{/blue}`
  - `{cyan}...{/cyan}`
  - `{purple}...{/purple}`
  - `{muted}...{/muted}`
  - `{small}...{/small}`
  - `{large}...{/large}`
- 対応箇所: 日記本文 / 撮影データの箇条書き / 所感本文
- タグはネスト可能（例: `{red}重要 {small}注記{/small}{/red}`）

## 5. 欠損時の扱い

- `## 日記` 欠損: 日記セクション非表示で継続。
- `## 観測記録` 欠損: 詳細ページはエラー扱いにする（404 かエラーメッセージ）。
- 対象ブロック内で `天体写真` が空: 対象は表示しつつ画像領域にプレースホルダを出す。
- 不明見出し: 無視するか補助テキストとして末尾に出す。ページ全体は壊さない。

## 6. 実装者向け注意（パーサー）

- 見出し抽出は行単位走査を基本にする。
- JavaScript 正規表現の終端に `\Z` は使わない。
- `#### 所感` は空文字を許容し、表示側で「未記入」を出せるようにする。
