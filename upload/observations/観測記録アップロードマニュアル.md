# 観測記録アップロードマニュアル

このファイルは、`upload/observations` フォルダに観測記録を追加するための実用手順。

## 1. 先に結論

- 1観測日ごとに `upload/observations/<year>/<date>/` フォルダを作る
- その中に `index.md` を1つ置く
- 画像は `index.md` と同じフォルダに置く
- 表示ルールは「タイトル → 天体写真 → 撮影データ → 所感」

## 2. フォルダ構成ルール

- `year` は4桁: 例 `2024`
- `date` は6桁 `YYMMDD`: 例 `240410`
- 最終的な構成:

```text
upload/
  observations/
    2024/
      240410/
        index.md
        diary-setup.jpg
        m42-final.jpg
        ic434-final.jpg
```

## 3. 作業手順

1. `upload/observations/<year>/<date>/` を作成する
2. `index.md` を作成する
3. `upload/observations/observation-entry.md` をコピーして `upload/observations/<year>/<date>/index.md` として使ってよい
4. 使う画像を同じフォルダにコピーする
5. `index.md` の `image:` や `![説明](ファイル名)` が実ファイル名と一致しているか確認する
6. 保存後、表示ページで日付と内容を確認する

## 4. Markdown の必須ルール

- `## 観測記録` は必須
- `## 日記` は任意
- 観測対象ごとに次を繰り返す
  - `### 対象名`
  - `#### タイトル`
  - `#### 天体写真`
  - `#### 撮影データ`
  - `#### 所感`

## 5. コピペ用テンプレート

## 6. 共通本文記法

- `image:` 同じフォルダの画像を読み込む
- `imageAlign:` `left` / `right` / `center`
- `align:` 段落単位の文字寄せ
- `clear: both` 以降の本文を横いっぱいに戻す
- 既存互換として `![説明](ファイル名)` 形式の単独行も中央画像として表示できる
- 装飾タグも引き続き使える: `{red}重要{/red}` / `{small}補足{/small}` / `**太字**`

### 装飾タグ一覧

- 色: `{red}` / `{green}` / `{yellow}` / `{orange}` / `{blue}` / `{cyan}` / `{purple}` / `{muted}`
- 文字サイズ: `{small}` / `{large}`
- 太字: `**...**`
- エイリアス: `{lime}` / `{gold}` / `{gray}` / `{grey}` / `{big}` / `{tiny}`

## 7. よくあるミス

- `date` を `YYYYMMDD` で作ってしまう
- `index.md` ではなく別名ファイルにしてしまう
- 画像ファイル名の大文字小文字が Markdown 記述と一致していない
- `## 観測記録` セクションを省略してしまう

## 8. 最終チェック

- フォルダは `upload/observations/<year>/<date>/` になっている
- `index.md` が存在する
- `## 観測記録` がある
- すべての画像リンクが開ける
- 観測対象の順序が意図どおり
