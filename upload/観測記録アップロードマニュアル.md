# 観測記録アップロードマニュアル

このファイルは、`upload` フォルダに観測記録を追加するための実用手順。

## 1. 先に結論

- 1観測日ごとに `upload/<year>/<date>/` フォルダを作る
- その中に `index.md` を1つ置く
- 画像は `index.md` と同じフォルダに置く
- 表示ルールは「タイトル → 天体写真 → 撮影データ → 所感」

## 2. フォルダ構成ルール

- `year` は4桁: 例 `2024`
- `date` は6桁 `YYMMDD`: 例 `240410`
- 最終的な構成:

```text
upload/
  2024/
    240410/
      index.md
      diary-setup.jpg
      m42-final.jpg
      ic434-final.jpg
```

## 3. 作業手順

1. `upload/<year>/<date>/` を作成する
2. `index.md` を作成する
3. `upload/observation-entry.md` をコピーして `upload/<year>/<date>/index.md` として使ってよい
4. 使う画像を同じフォルダにコピーする
5. `index.md` の `![説明](ファイル名)` が実ファイル名と一致しているか確認する
6. 保存後、表示ページで日付と内容を確認する

## 4. Markdown の必須ルール

- `## 観測記録` は必須
- `## 日記` は任意
- 観測対象ごとに次を繰り返す
  - `### 対象名`
  - `#### タイトル`
  - `#### 天体写真`
  - `#### 撮影データ`
  - `#### 所感`

## 6. よくあるミス

- `date` を `YYYYMMDD` で作ってしまう
- `index.md` ではなく別名ファイルにしてしまう
- 画像ファイル名の大文字小文字が Markdown 記述と一致していない
- `## 観測記録` セクションを省略してしまう

## 7. 最終チェック

- フォルダは `upload/<year>/<date>/` になっている
- `index.md` が存在する
- `## 観測記録` がある
- すべての画像リンクが開ける
- 観測対象の順序が意図どおり
